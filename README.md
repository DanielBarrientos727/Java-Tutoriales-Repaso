# Java-Tutoriales-Repaso

Repositorio personal para repasar y practicar Java durante mi formación en Ingeniería de Sistemas y Computación.

La idea es acompañar el estudio de tutoriales con código propio, pequeños ejercicios, apuntes y ejemplos que permitan volver a los conceptos cuando sea necesario.

## Objetivo

Fortalecer las bases de Java mediante práctica constante y repaso de los conceptos fundamentales del lenguaje.

Este repositorio no busca reunir proyectos grandes, sino servir como una especie de cuaderno de práctica en código.

## Contenido

* Fundamentos de Java
* Variables y tipos de datos
* Operadores y expresiones
* Condicionales
* Ciclos
* Métodos
* Arreglos
* Programación Orientada a Objetos
* Excepciones
* Colecciones
* Archivos
* Otros temas que vaya estudiando

## Forma de estudio

Cada tema se trabaja siguiendo esta idea:

**Tutorial → entender → escribir código → modificarlo → practicar → repasar**

Los ejemplos del tutorial pueden servir como referencia, pero se intentará escribir y modificar el código para comprobar que realmente se entiende.

Este repositorio forma parte de mi proceso de aprendizaje de Java y complementa los ejercicios y trabajos realizados para la Universidad del Quindío.
