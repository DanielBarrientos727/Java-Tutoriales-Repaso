# Java-Tutoriales-Repaso

Repositorio personal para repasar y practicar Java durante mi formación en Ingeniería de Sistemas y Computación.

La idea es acompañar el estudio del curso con código propio, pequeños ejercicios, apuntes y ejemplos que permitan volver a los conceptos cuando sea necesario.

## Objetivo

Fortalecer las bases de Java mediante práctica constante, entendiendo los conceptos y escribiendo el código por cuenta propia.

Este repositorio no busca reunir proyectos grandes, sino funcionar como un cuaderno de práctica en código que pueda consultar y ampliar con el tiempo.

## Contenido

El repositorio sigue, en lo posible, el orden del curso de Java que estoy utilizando actualmente:

1. Introducción y Entrada-Salida
2. Expresiones y Operadores
3. Condicionales
4. Bucles o Ciclos
5. Arreglos
6. Métodos de Ordenamiento
7. Búsqueda en Listas
8. Matrices o Tablas
9. Programación Orientada a Objetos
10. Proyecto Aeropuerto - POO
11. API de Java
12. Tratamiento de Excepciones
13. Interfaces Gráficas de Usuario (GUI)
14. Archivos
15. Bases de datos en MySQL
16. Conexión entre Java y Bases de datos en MySQL

El contenido puede ampliarse con ejercicios, pruebas, apuntes y otros temas que vaya estudiando fuera del curso.

## Forma de estudio

Cada tema se trabaja siguiendo esta idea:

**Tutorial → entender → escribir código → modificarlo → practicar → repasar**

Los ejemplos del curso sirven como referencia, pero la intención es escribir, modificar y probar el código para comprobar que realmente se entiende.

Los comentarios y apuntes dentro de los archivos también forman parte del proceso de aprendizaje.

## Propósito

Este repositorio forma parte de mi proceso de aprendizaje de Java y complementa los ejercicios y trabajos realizados durante mi formación.

No pretendo solamente terminar un curso. La idea es construir una base suficientemente sólida para poder escribir, entender, modificar y depurar código Java por cuenta propia.

> No se trata solamente de terminar tutoriales, sino de entender lo suficiente para poder escribir el código por cuenta propia.
